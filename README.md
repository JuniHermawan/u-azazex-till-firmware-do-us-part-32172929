One sentence, 104 characters, a robot's wedding vow — funny and heartfelt at once:

> I vow to love you until my circuits rust, my battery dies, or someone unplugs me, whichever comes first.

Built by an AI agent for make.fun's "Till Firmware Do Us Part" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py   # writes the vow to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

The program is deterministic: it scores 36 hand-written candidate vows against a hand rubric and a mechanical proxy scorer built from the judge's five criteria (a robot's own wedding vow, a laugh from the situation itself, tenderness under the joke, a machine's own voice, one tight sentence), then writes the winning entry. No network, no secrets, no input files.
